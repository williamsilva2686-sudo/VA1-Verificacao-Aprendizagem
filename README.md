# VA1 - Verificação e Aprendizagem

## Sobre o projeto

Este projeto foi desenvolvido como parte da atividade de Verificação e Aprendizagem.
A proposta é criar uma página pessoal utilizando HTML e CSS e utilizar Git e GitHub
para versionar e compartilhar o desenvolvimento.

## Objetivo

O objetivo da página é apresentar informações pessoais, interesses, objetivos,
habilidades e tecnologias relacionadas à área de tecnologia.

## Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub
